💸 Echo Pay – Voice-Based Payment Platform

Echo Pay is a simple and secure voice-enabled payment app that allows users to send and receive money just by speaking.
It supports JWT authentication, real-time transactions, and an intuitive React interface for smooth user experience.

🚀 Features

🎙️ Voice-based payments – make transactions using voice commands

🔐 JWT authentication – secure sign-up and login flow

💳 Instant transaction generation – auto-generate payment amounts and track history

⚡ Built with React + Node.js + MongoDB for seamless performance

🛠️ Tech Stack

Frontend: React, Tailwind CSS
Backend: Node.js, Express.js, MongoDB, JWT
